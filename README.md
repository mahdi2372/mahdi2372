# Reverse Engineer • Software Developer • AI Builder

## About

I work at the intersection of **reverse engineering, binary analysis, software development, and AI-assisted problem solving**. My main focus is understanding Windows executable applications at the binary level, automating repetitive analysis, and turning difficult technical problems into clear, useful tools.

I enjoy moving between low-level behavior and high-level product thinking: observing how software works, forming precise hypotheses, validating them, and building reliable solutions around what I learn.

> **Understand the binary. Automate the hard parts. Build better systems.**

### Engineering output

- **Analysis:** turn unknown behavior into documented, testable understanding
- **Automation:** replace repetitive investigation with reliable scripts and tools
- **Applications:** build focused desktop, web, and developer experiences
- **Integration:** connect analysis, APIs, local tools, and AI-assisted workflows
- **Documentation:** make complex technical findings useful to other people

## How I work

| Step | Principle |
| --- | --- |
| **Observe** | Start with behavior, evidence, constraints, and a clear question |
| **Model** | Build a precise mental model of the system and its boundaries |
| **Validate** | Test assumptions with repeatable experiments and careful tooling |
| **Automate** | Script the repeatable parts and keep the workflow reproducible |
| **Deliver** | Turn the result into a useful tool, explanation, or maintainable system |

## Research standard

Reverse engineering and security work should be responsible. My security-related work is intended for **owned software, learning, defense, privacy, and explicitly authorized testing only**. I value responsible disclosure, least privilege, secure defaults, and research that improves understanding without enabling harm.
