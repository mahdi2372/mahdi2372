# Mahdi | Polyglot Software Developer

I design and build software across the complete product lifecycle: web platforms, APIs, desktop and cross-platform applications, automation, developer tools, cloud-ready services, and security-focused utilities.

I work across languages and ecosystems, selecting technology based on the product, constraints, performance requirements, and people who will use it. The result should be more than code: it should be reliable, understandable, secure, and useful.

## 🧭 Engineering standard

| Stage | What I optimize for |
| --- | --- |
| **Discover** | Understand the problem, users, constraints, risks, and definition of success |
| **Design** | Choose a clear architecture, data flow, interface, and technology strategy |
| **Build** | Write modular, readable, testable code with a strong developer experience |
| **Harden** | Apply validation, least privilege, secure defaults, error handling, and performance checks |
| **Ship** | Document the system, automate repeatable work, and make deployment predictable |

## 🛡️ Security & responsible engineering

Security work should make people and systems safer. Any security-related development represented here is for **learning, defense, privacy, and authorized testing only**. I value responsible disclosure, least privilege, secure defaults, careful data handling, and tools that reduce risk instead of creating it.

## ✅ Quality checklist

- **Maintainability:** understandable structure, useful names, focused modules, and documentation
- **Reliability:** validation, error handling, tests where they provide confidence, and predictable behavior
- **Security:** secure defaults, minimal permissions, privacy-aware decisions, and authorized use
- **Performance:** efficient data flow, sensible caching, responsive interfaces, and measured improvements
- **Accessibility:** inclusive interfaces, readable content, clear feedback, and thoughtful user experience
- **Delivery:** reproducible environments, version control, automation, and a path from prototype to production
